# Rincones

Mis rincones favoritos. Blog de viajes hecho con [Astro](https://astro.build) y
publicado en GitHub Pages.

Cada viaje agrupa varios rincones, y cada rincón tiene sus fotos y su texto.

Para trabajar en local:

```sh
npm install
npm run dev
```

Las instrucciones para agregar viajes y rincones están en `CLAUDE.md`.
